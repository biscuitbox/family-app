# 우리집 성장 앱 — 1~6단계 전체

아이가 스스로 등교 준비와 내일 준비를 해내고, 부모는 묻지 않고 현관 대시보드로 확인하는 가족 앱입니다.
GitHub Pages(무료 호스팅) + Firebase(로그인·실시간 공유)로 돌아가는 PWA라서, 홈 화면에 앱처럼 설치해 씁니다.

## 1단계: 아침 등교 준비

| 화면 | 내용 |
| --- | --- |
| 첫째 (카드) | 한 화면에 한 단계, 사진 카드, 소리로 읽어 주기, 숫자 없는 시간 막대, 하나씩 누르는 확인 목록(복장·준비물) |
| 둘째 (체크리스트) | 한 화면 체크리스트, 시간표 준비물 자동 포함, 완료 시각 기록, 출발까지 남은 시간 |
| 시간대 자동 전환 | 아침 시작~출발은 "등교 준비", 저녁 시작~잠잘 시간은 "내일 준비", 나머지는 쉬는 시간 |
| 부모: 현관 대시보드 | 두 아이 진행률, 남은 단계 이름, 덜 챙긴 준비물, 완료 시각, 별 수 (실시간) |
| 부모: 설정 | 루틴 편집(사진 넣기, 순서, 확인 목록), 요일별 시간표 준비물, 아이별 화면 방식·글자 크기·음성·효과음, 하루 시간, 학교 가는 요일, 아이 기기 연결 |

## 2단계: 공부 기록 · 독서와 필사 · 아빠 기록

아이 화면 아래에 **오늘 / 공부 / 책·필사** 탭이 생겼습니다. 등교 준비와 내일 준비 시간에는 "오늘" 탭이 그 화면을 보여 주고, 나머지 시간에는 오늘 할 일(공부·독서·필사)과 아빠의 오늘이 보입니다.

| 화면 | 내용 |
| --- | --- |
| 공부 (첫째) | 요일별 공부 카드를 한 장씩: 과목·할 일 → 시작 → 숫자 없는 타이머 막대(다 줄면 소리로 알림) → 다 했어요 → 기분 3개 중 고르기 |
| 공부 (둘째) | 오늘 계획 목록(부모가 정한 카드 + 아이가 더한 계획), 시작·끝 타이머, 한 줄 소감, 이번 주 공부 시간 막대그래프 |
| 독서 | 내 책장(표지 사진), 오늘 몇 쪽까지 읽었는지, 한 줄 느낌, 다 읽은 책 |
| 필사 (첫째) | 오늘 쓸 쪽 정하기(기본 2쪽) → 한 쪽 쓰고 사진 → 1분 쉬기 → 다음 쪽 → 마음에 든 문장(선택) |
| 필사 (둘째) | 한 단락 쓰고 사진 → 마음에 든 문장과 고른 이유(필수) |
| 나의 문장 모음 · 이번 달 필사 | 고른 문장이 모이고, 한 달 필사 사진을 작은 사진으로 모아 봅니다 |
| 부모: 현관 대시보드 | 지금 공부 중 표시와 경과 시간, 오늘 과목별 공부 시간과 소감, 독서 쪽수, 필사 사진(누르면 크게), 아빠 패널 |
| 부모: 아빠 기록 | 운동(종류·시간), 독서(책·쪽·나눌 문장), 연구 활동(한 줄·시간). 기록마다 아이들에게 숨기기·보이기 |
| 부모: 공부 계획 · 아이 설정 | 요일별 공부 카드, 한 번 공부 시간, 필사 단위·분량·쉬는 시간·문장 필수 여부 |

별은 하루에 공부·독서·필사 각각 1개씩 받습니다 (여러 번 해도 하루 1개라 용돈 연결 시 부풀지 않음).

### 사진 크기
| 사진 | 긴 변 | 용량 |
| --- | --- | --- |
| 루틴 카드 | 720px | 80KB 이하 |
| 책 표지 | 400px | 40KB 이하 |
| 필사 공책 | 1600px | 250KB 이하 (글씨가 읽히는 크기) |
| 필사 미리보기 | 320px | 18KB 이하 |

필사 사진은 미리 받아 두지 않고 화면에 나올 때만 불러옵니다. 갤러리와 대시보드는 작은 미리보기만 받고, 누를 때 원본을 엽니다.

### 1단계에서 올라오는 경우
1. `firestore.rules`를 새 내용으로 다시 붙여 넣고 **게시**하세요 (책장·문장·사진·숨긴 기록 규칙이 추가됨).
2. 기존 설정에는 2단계 기본값(과목, 예시 공부 카드, 필사 분량)이 자동으로 채워집니다. **공부 계획** 탭에서 실제 계획으로 바꿔 주세요.
3. 서비스 워커 VERSION은 최신 버전으로 올려 두었습니다.

> 아이들에게 숨긴 아빠 기록은 부모만 읽을 수 있는 별도 저장소(`notes`)로 옮겨져서, 아이 기기에서는 내용 자체를 받지 못합니다.

## 3단계: 응원과 인성

아이 화면 아래 탭에 **가족**이 더해졌습니다 (오늘 / 공부 / 책·필사 / 가족).

| 화면 | 내용 |
| --- | --- |
| 감정 체크인 | 아침(오후 3시 전)과 저녁에 기분 5가지 중 고르기. 둘째는 이유 한 줄(선택). 등교 준비·내일 준비를 마친 화면에서도 물어봄 |
| 아빠의 한마디 | 부모가 대시보드에서 아이에게 한마디(무엇에 대한 것인지 + 이모지). 아이 "오늘" 화면에 뜨고, 첫째는 소리로 들을 수 있음. "고마워요"를 누르면 부모 화면에 "읽음" |
| 오늘의 미션 | 등교 준비(학교 가는 날)·공부·필사를 다 하면 보너스 별 1개 |
| 연속 기록 · 쉬어 가기 카드 | 미션을 다 한 날이 이어지면 🔥 연속 기록. 학교 가는 날을 빠뜨려도 쉬어 가기 카드(한 주 2장)가 자동으로 지켜 줌. 주말은 빠져도 끊기지 않음 |
| 별로 바꾸기 | 가족 활동·용돈을 별로 신청 → 부모가 승인하면 별이 빠짐 |
| 형제 협동 미션 | 두 아이가 한 주에 함께 필사 10쪽을 채우면 각자 별 2개 (각자 "협동 보상 받기") |
| 칭찬 카드 | 아이·아빠 누구나 가족에게 칭찬 카드(문구 고르기 또는 직접 쓰기) |
| 이번 주 돌아보기 | 한 주 기록 요약 + 각자 잘한 것 1개, 바꿀 것 1개, 이번 주의 문장, 받은 칭찬 카드. 일요일에는 아이 화면에 알림 띠 |
| 부모: 대시보드 | 아이별 기분, **이틀 연속 힘든 기분(속상해요·화나요)이면 부모 화면에만 알림**, 한마디 보내기와 읽음 표시, 이번 주 별와 연속 기록 |
| 부모: 보상 | 승인 기다리는 신청, 이번 주 용돈 정산 합계, 바꿀 수 있는 것 편집, 주간 별 상한(기본 25개)·쉬어 가기 카드 수·협동 미션 목표 |

### 2단계에서 올라오는 경우
1. `firestore.rules`를 새 내용으로 다시 게시하세요. 칭찬 카드·돌아보기·보상 신청 규칙이 추가되었고, 아이 기기는 **쓴 별(spent)를 고칠 수 없게** 바뀌었습니다.
2. 보상 목록과 규칙 기본값이 설정에 자동으로 채워집니다. **보상** 탭에서 우리 집에 맞게 바꿔 주세요.
3. `sw.js`의 VERSION은 `ugh-v3`로 올려 두었습니다.

## 4단계: 생활과 책임

아이 화면 아래 탭에 **생활**이 더해졌습니다 (오늘 / 공부 / 책·필사 / 생활 / 가족). 생활 안에는 집안일 · 생활 기술 · 용돈 세 칸이 있습니다.

| 화면 | 내용 |
| --- | --- |
| 집안일 | 요일별로 맡은 일 체크. 오늘 몫을 다 하면 별 1개. 생활 기술과 이어 둔 집안일은 "방법 보기"로 단계 안내 |
| 생활 기술 (첫째) | 샤워·빨래 개기·간식 만들기·버스 타기·편의점 계산 등을 등교 준비처럼 한 화면 한 단계 카드로 연습. 단계마다 소리로 읽어 줌 |
| 생활 기술 (둘째) | 계란 프라이·버스 길 찾기·방 정리를 체크리스트로 연습 |
| 성장 단계 | 기술마다 **함께 → 지켜봐 줌 → 혼자**. 연습을 마치면 "누구랑 했어요?"를 고르고, "혼자"를 3번 고르면 부모 대시보드에 단계를 올려 줄지 알림. 단계는 부모가 정함 |
| 할 수 있어요 | "혼자" 단계가 된 기술이 모여 성장이 보임 |
| 용돈 기입장 | 받았어요 · 썼어요(그림 분류: 간식, 장난감, 학용품, 선물, 기타) · 저금했어요. 지갑과 저금통 금액 자동 계산. 별로 바꾼 용돈은 승인되면 자동으로 "받은 돈"에 들어감 |
| 저축 목표 | 사고 싶은 것의 사진과 가격 → 저금통이 차오르는 막대 → 목표 달성 후 "샀어요" |
| 부모: 생활 탭 | 집안일(요일, 생활 기술과 잇기), 생활 기술(이름·영역·지금 단계, 단계마다 사진 넣기), 아이별 용돈 기입장 보기 |
| 부모: 대시보드 | 오늘 집안일, 생활 기술 연습(누구랑 했는지), "혼자" 3번 알림 |

생활 기술 단계 사진은 루틴 카드와 같은 방식으로 자동으로 줄여서(80KB 이하) 저장합니다.

### 3단계에서 올라오는 경우
1. `firestore.rules`를 다시 게시하세요 (용돈 기입장 `money`, 저축 목표 `goals` 규칙 추가).
2. 예시 집안일과 생활 기술이 설정에 자동으로 채워집니다. 부모 **생활** 탭에서 우리 집에 맞게 바꾸고, 첫째 생활 기술에는 실제 욕실·빨래 바구니 사진을 넣어 주세요.
3. 서비스 워커 VERSION은 `ugh-v4`로 올려 두었습니다.

## 5단계: 운영 도우미

| 기능 | 내용 |
| --- | --- |
| 가정통신문 사진 등록 (부모 → 가정통신문 탭) | 알림장·가정통신문을 찍으면 AI가 날짜와 준비물을 찾아 줌 → 날짜·대상·준비물을 확인하고 고쳐서 "준비물에 넣기". 그날 아침 "가방 확인"과 전날 저녁 "가방 싸기" 카드에 시간표 준비물과 함께 나옴. AI 없이 "직접 넣기"도 가능. 지난 날짜는 자동으로 정리 |
| 기기 사용 규칙 (부모 → 시간 탭) | 아이 "오늘" 화면에 자유 시간 카드. 오늘의 미션을 다 하면 🔒이 🎮로 열림 |
| 방학 모드 (부모 → 시간 탭) | 방학 기간에는 등교 준비 대신 "방학 아침" 루틴이 일어날 시간에 열리고, 내일 준비·준비물은 쉼. 개학 전 마지막 7일은 개학 연습 주간이라 평소 등교 준비로 돌아감. 방학 중 빠진 날은 연속 기록에서 학교 가는 날과 같게 셈. 방학 아침 루틴은 루틴 탭 "방학 아침"에서 편집 |

### 가정통신문 AI 읽기 설정
1. https://aistudio.google.com 에서 API 키를 만듭니다.
2. 부모 화면 → **가정통신문** 탭 → **AI 설정**에 키를 넣습니다. 키는 **그 기기 브라우저에만** 저장되고 Firestore나 앱 코드에는 들어가지 않습니다. 다른 기기에서 쓰려면 그 기기에서 한 번 더 넣으세요.
3. 기본 모델은 `gemini-3.1-flash-lite`입니다. Google이 모델 이름을 바꾸면 "모델 이름을 찾을 수 없어요"라고 나오니, AI Studio에서 지금 쓰는 이름을 확인해 바꿔 주세요.
4. 사진은 분석할 때만 Google로 보내고 앱에는 저장하지 않습니다.

## 6단계: 알림 · 다듬기 · 연말 성장 앨범

| 기능 | 내용 |
| --- | --- |
| 캐릭터 알림 | 등교 준비·내일 준비·공부·필사 시간이 되면 캐릭터("우리별", 이름·그림 바꾸기 가능)가 아이 화면 맨 위에서 알려 주고 "지금 하기"로 바로 이동. 첫째는 소리로도 읽어 줌. 이미 한 일은 알리지 않음. "알림 허용하기"를 누르면 휴대폰 알림으로도 뜸 |
| 다듬기 | 아이별 "읽어 주는 속도"(느리게 · 조금 느리게 · 보통), 한국어 받침에 맞는 조사, 그래프 글씨 크기, 방학 문구 |
| 성장 앨범 | 아이 "가족" 탭 또는 부모 "돌아보기" 탭에서. 올해 숫자(등교 준비·공부·독서·필사·집안일·생활 기술·별·칭찬 카드), 달마다 공부 시간, 다 읽은 책, 나의 문장, 혼자 할 수 있게 된 일, 이룬 저축 목표, 달마다 모은 필사 사진, 받은 칭찬 카드. "PDF로 저장"을 누르고 인쇄 창에서 "PDF로 저장"을 고르면 한 권으로 저장 |

### 알림에 대해 알아 둘 점
지금 알림은 **앱이 열려 있거나 홈 화면 앱이 켜져 있을 때** 동작합니다. 앱을 완전히 닫아 둔 휴대폰에 정해진 시간에 알림을 보내려면, 정해진 시간에 알림을 "보내 주는" 서버가 따로 필요합니다(Firebase Cloud Functions는 유료 요금제, 무료로는 GitHub Actions 예약 실행 같은 방법). 또 Firebase의 웹 알림 등록 방식이 2026년에 바뀌고 있어서, 실제 Firebase 프로젝트를 연결한 뒤 함께 시험하면서 붙이는 것이 안전합니다.

### 5·6단계로 올라오는 경우
1. `firestore.rules`는 4단계와 같습니다 (새 컬렉션 없음).
2. 방학·기기 규칙·알림·캐릭터 기본값과 "방학 아침" 루틴이 설정에 자동으로 채워집니다.
3. 서비스 워커 VERSION은 `ugh-v5`로 올려 두었습니다.

말도 맞췄습니다: 스티커 → **별**, 퀘스트 → **미션**, 연속 기록 → **연속 발사**, 현관 대시보드 → **관제 센터**.

`config.js`를 비워 두면 **체험 모드**로 열립니다 (이 브라우저에만 저장, 예시 데이터).

## 파일

```
index.html       화면 뼈대
styles.css       디자인
app.js           화면과 동작
store.js         데이터 저장 (체험 모드 / Firebase)
config.js        ← Firebase 설정을 붙여 넣는 곳
firestore.rules  ← Firebase 보안 규칙 (콘솔에 붙여 넣기)
manifest.json, sw.js, icons/   홈 화면 설치용
```

## 실제로 쓰기까지 (처음 한 번, 약 20분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가** (예: `our-family-app`). 요금제는 무료(Spark) 그대로 둡니다.
2. **Authentication → 시작하기 → 로그인 방법**에서 두 가지를 켭니다.
   - **Google** (부모 로그인)
   - **익명** (아이 기기 로그인)
3. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 를 추가합니다.
4. **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드.
5. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**.
6. **프로젝트 설정(톱니) → 내 앱 → 웹 앱 추가(</>)** → 나오는 `firebaseConfig` 값을 `config.js`의 `window.FIREBASE_CONFIG = { ... }`에 붙여 넣습니다.

> 사진은 앱에서 찍거나 앨범에서 고르면 자동으로 줄여서(긴 변 720px, 80KB 이하) Firestore에 저장합니다. 1,000만 화소 사진도 수십 KB가 됩니다. Cloud Storage는 이제 유료(Blaze) 요금제가 있어야 쓸 수 있기 때문입니다. 가족 사용량이면 Firestore 무료 한도로 충분합니다.

### 2. GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만들고(예: `family-app`), 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages → Branch: main / root → Save**.
3. 몇 분 뒤 `https://내아이디.github.io/family-app/` 로 열립니다.

> `config.js`의 Firebase 웹 설정은 공개되어도 되는 값입니다. 데이터는 `firestore.rules`가 지킵니다. 규칙을 꼭 게시하세요.

### 3. 가족 연결하기
1. **부모 기기**: 주소를 열고 "구글 계정으로 시작" → 우리 가족 공간이 만들어집니다.
2. 부모 화면 **가족 연결** 탭 → "첫째 초대 코드 만들기" → 8자리 코드가 나옵니다 (24시간 유효).
3. **첫째 기기**: 같은 주소를 열고 "아이 기기 연결"에 코드 입력 → 이 기기는 계속 첫째 화면으로 열립니다.
4. 둘째도 같은 방법으로 연결합니다.

### 4. 홈 화면에 설치
- 아이폰: Safari로 열기 → 공유 → **홈 화면에 추가**
- 안드로이드: Chrome으로 열기 → 메뉴 → **홈 화면에 추가 / 앱 설치**
