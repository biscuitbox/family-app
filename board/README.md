# 관제 센터 보드 (Guition JC8012P4A1C)

거실 벽에 거는 10.1인치 터치 화면입니다. 웹 앱과 **같은 Firebase 가족 공간**에 '보드' 기기로 연결해서, 두 아이가 등교 준비·내일 준비·집안일·감정 체크인을 보드에서 체크합니다. 체크는 폰 앱·관제 센터에 바로 보이고, 별은 웹 앱이 계산해 넣습니다.

## 이번 버전에 들어 있는 것

| 시간대 | 아이 칸에 보이는 것 | 보드에서 누르는 것 |
| --- | --- | --- |
| 등교 준비 (학교 가는 날 06:40 ~ 출발 + 30분) | 연료 게이지 시간 막대, 루틴 단계, 시간표·가정통신문 준비물 | 단계 완료, 확인 항목 |
| 내일 준비 (내일 학교 가는 날 19:30 ~ 잠잘 시간 + 60분) | 내일 준비 단계, 내일 준비물 | 단계 완료, 확인 항목 |
| 그 밖의 낮 | 오늘의 미션, 공부·독서·필사·집안일 상태, 연속 발사 | 집안일 체크, 감정 체크인 |
| 밤 | 시계와 오늘 해낸 것, 화면 어둡게 | 누르면 30초 밝아짐 |

- 시간과 루틴은 부모 앱 설정을 그대로 따릅니다. 아이 설정이 '카드'면 한 단계씩, '목록'이면 체크리스트로 보입니다.
- 위 띠에는 날짜·시계와 아빠의 오늘(아이들에게 보이게 둔 기록만)이 나옵니다.
- 아빠의 한마디는 그 아이 칸 위에 한 줄로 나옵니다.
- 기분은 고른 뒤 "체크인 했어요"만 보이고, 무엇을 골랐는지는 보드에 나오지 않습니다.

**아직 없는 것 (다음 단계):** 공부 타이머 시작·끝, 루틴 카드 사진, 아이별 글자 크기 배율, 화면에서 Wi-Fi 바꾸기. 지금은 Wi-Fi를 빌드할 때 넣습니다.

## 처음 한 번

### 1. 웹 앱 쪽 (먼저)
1. 이 저장소의 `firestore.rules`를 Firebase 콘솔 → Firestore → 규칙에 붙여 넣고 **게시**합니다. 보드 연결과 보드의 기록 쓰기 규칙이 들어 있습니다.
2. 바뀐 웹 앱이 GitHub Pages에 올라가 있어야 "보드 초대 코드 만들기" 버튼이 보입니다.

### 2. 빌드 준비
- [ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/latest/esp32p4/get-started/) 5.5 이상을 설치합니다.
- 부품(LVGL 9, esp_lvgl_port, JD9365 화면, GSL3680 터치, esp_hosted/esp_wifi_remote)은 처음 빌드할 때 `main/idf_component.yml`에 따라 자동으로 받아집니다.

```bash
cd board
idf.py set-target esp32p4
idf.py menuconfig        # "관제 센터 보드"에서 Wi-Fi 이름·비밀번호
idf.py build flash monitor
```

`sdkconfig`에는 Wi-Fi 비밀번호가 들어가므로 저장소에 올리지 않습니다(`.gitignore`에 넣어 둠).

### 3. 가족에 연결
1. 부모 앱 → **가족 연결** → **보드 초대 코드 만들기** → 8자리 코드가 나옵니다 (24시간 유효).
2. 보드 화면의 키보드로 코드를 넣고 **연결하기**.
3. 부모 앱의 연결된 기기 목록에 "관제 센터 보드"가 보이면 끝입니다. 여기서 **연결 해제**하면 보드는 바로 아무것도 읽지 못하고 다시 코드 입력 화면으로 돌아갑니다.

## 처음 켤 때 막히면

이 펌웨어의 화면·터치·Wi-Fi 설정은 공개된 커뮤니티 자료를 기준으로 했고, 실제 보드에서는 아직 시험하지 않았습니다. 보드 판(revision)마다 다를 수 있습니다.

| 증상 | 확인할 것 |
| --- | --- |
| 백라이트만 켜지고 화면이 비어 있음 | 패널 판이 다른 경우입니다. 뒷면 스티커의 괄호 숫자(배치)가 2624 이후면 V2 패널이고, 지금 코드(`main/jc8012_v2_init.h`, 70MHz, 리셋 GPIO 27)가 그 패널용입니다. 그 전 배치라면 ESPHome `mipi_dsi/models/guition.py`의 `JC8012P4A1` 표와 60MHz·vsync 8/20 타이밍으로 바꿉니다. |
| 터치가 안 되거나 좌우가 바뀜 | `hw.c`의 터치 핀(SDA 7, SCL 8, RST 22, INT 21)과 `mirror_x`를 확인합니다. |
| Wi-Fi가 안 붙음 | 보드의 ESP32-C6 펌웨어가 오래되어 esp_hosted와 맞지 않는 경우가 있습니다. C6를 esp_hosted 최신 펌웨어로 올리고, P4–C6 연결(SDIO) 핀을 Guition 예제의 `sdkconfig`와 맞춥니다. |
| "기록을 못 받고 있어요" | 시리얼 모니터에서 HTTP 상태를 봅니다. 403은 규칙 게시 전이거나 연결 해제, 400/401은 API 키 문제입니다. Google Cloud 콘솔에서 웹 API 키에 '웹사이트' 제한을 걸었다면 보드용 키를 따로 만들어 menuconfig에 넣습니다. |
| ESP-IDF 6.x에서 빌드 오류 | 화면 설정은 버전에 따라 나뉘어 있습니다(`hw.c`의 `ESP_IDF_VERSION` 분기). 부품 버전을 `idf_component.yml`에서 맞춰 봅니다. |

## 어떻게 동작하나

- **읽기:** 오늘 두 아이와 아빠의 하루 기록을 `batchGet` 한 번으로 읽습니다. 등교 준비·하교 후(15시 이후)·내일 준비·주말 낮에는 10초, 학교에 있는 시간과 밤에는 2분마다. 설정은 5분마다 필요한 칸만 받습니다. 하루 1만 4천~1만 8천 번 읽기로, Firestore 무료 한도(하루 5만 번) 안입니다.
- **쓰기:** 누르면 화면에 먼저 표시하고, 앱과 같은 경로(`morning.steps.m3` 등)에 `updateMask`로 그 칸만 보냅니다. 인터넷이 끊기면 줄에 모아 두었다가 순서대로 보냅니다.
- **별:** 보드는 `awarded`·`stars`·`quests`를 쓰지 않습니다(규칙에서도 막음). 웹 앱의 `reconcileAwards()`가 "다 했는데 별이 없는" 활동을 찾아 별·오늘의 미션·연속 발사를 채웁니다. 보드에서 체크한 날에는 그날 안에 폰 앱이나 부모 관제 센터가 한 번 열려야 별이 들어갑니다.
- **보드가 못 보는 것:** 숨긴 아빠 기록, 용돈 기입장·저축 목표, 별 바꾸기 신청 (규칙에서 막음).

## 파일

```
main/
  main.c        시작
  hw.c          화면(JD9365 MIPI-DSI)·터치(GSL3680)·백라이트·LVGL
  net.c         Wi-Fi(ESP32-C6, esp_hosted)·SNTP(KST)
  cloud.c       익명 로그인·토큰 갱신·초대 코드 연결·Firestore REST
  sync.c        읽기 간격, 보내기 줄
  ui.c          화면 (LVGL 9)
  model.c       앱의 시간대·루틴 규칙을 C로 옮긴 것
  fs_json.c     Firestore 값 변환, 눌렀을 때 고칠 내용(app.js setStep/setItem/settle)
  ikey.c        확인 항목 키 (app.js ikey와 같은 계산)
  fonts/        한글 글꼴 (IBM Plex Sans KR을 KS X 1001 한글 2,350자 + 영숫자로 줄인 것, OFL)
test/
  run.sh        컴퓨터에서 C 규칙 코드를 빌드해 app.js와 결과 비교
```

## 앱 규칙을 고쳤을 때

`app.js`의 `autoMode`, `routineSteps`, `ikey`, `vacationState` 같은 규칙을 바꾸면 `main/model.c`도 같이 고친 뒤 시험을 돌립니다.

```bash
board/test/run.sh    # gcc, node 18+ 필요
```

`run.sh`는 app.js의 함수를 그대로 꺼내 2주치 시각(10분 간격) × 두 아이 × 두 설정(학기 중, 방학)에서 시간대·남은 시간·루틴 단계·확인 항목 키를 보드 코드와 비교합니다. 다른 곳이 0개여야 합니다.

## 글꼴

보드 글꼴은 KS X 1001 한글 2,350자만 들어 있습니다. 루틴 이름이나 아이 이름에 드문 글자(예: 뷁)가 있으면 그 글자만 빈칸으로 보입니다. 모든 한글 11,172자가 필요하면 `pyftsubset`으로 다시 만들 수 있습니다(글꼴 하나에 약 2.2MB). 이모지는 보드 화면에서 빼고 보여 주며, 확인 항목 키 계산에는 원래 글자를 그대로 씁니다.

글꼴은 IBM Plex Sans KR(SIL Open Font License 1.1)을 줄인 것이라 이름을 'Uri Board Sans KR'로 바꿨습니다. 라이선스는 `main/fonts/OFL.txt`에 있습니다.
